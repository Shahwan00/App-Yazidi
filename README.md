# MyConnect — مشروع شبكة اجتماعية + تعلم اللغات

هذا مشروع Front-end جاهز كبداية لـ GitHub Pages.

## الصفحات
- الرئيسية
- الملف الشخصي
- الأصدقاء
- المجموعات
- الرسائل
- الإشعارات
- الإعدادات
- مركز تعلم اللغات
- درس تفاعلي مع نطق صوتي وتقدم

## النشر على GitHub Pages
1. أنشئ Repository جديدًا، مثلاً `myconnect`.
2. ارفع جميع الملفات الموجودة في هذا المجلد.
3. افتح **Settings → Pages**.
4. في **Build and deployment** اختر **Deploy from a branch**.
5. اختر `main` و`/ (root)` ثم Save.
6. بعد النشر افتح رابط GitHub Pages الذي يعرضه GitHub.

## مهم
هذه نسخة Front-end تعمل مباشرة بدون خادم. البيانات الحالية تجريبية داخل JavaScript.

لتحويلها إلى تطبيق حقيقي متعدد المستخدمين نحتاج Backend وقاعدة بيانات، مثل:
- Firebase Authentication + Firestore + Storage
أو
- Supabase Auth + Database + Storage

بعد ربط Backend يمكن إضافة:
- تسجيل/إنشاء حساب حقيقي
- رفع صور وفيديو
- منشورات محفوظة في قاعدة البيانات
- أصدقاء حقيقيون
- رسائل فورية
- مجموعات
- حفظ تقدم تعلم اللغة لكل مستخدم
- دورات A1–C2
- نظام نقاط وشارات
- لوحة إدارة للمحتوى
